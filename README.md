# C Programming Challenges — YouCode

A collection of C programming exercises and mini-projects organized by training day, created to practice core programming concepts at YouCode.

## Contents

- **day1:** loops and iteration exercises.
- **day2:** arrays, functions, and a mini-project.
- **day3:** strings, structures, and practice programs.
- **day4:** a programming project.
- **day5:** a final project for animal records, alongside a sample CSV file.

The final animal-management program includes a terminal menu for adding, viewing, editing, deleting, searching, and viewing statistics about animals.

## Technologies

C, standard C libraries, command-line programs, and CSV data in the final-project folder.

## Running an exercise

Choose a C source file in a day folder and compile it with a C compiler, for example GCC:

~~~bash
gcc day5/Projet_Fin_SAS.c -o animal_manager
./animal_manager
~~~

On Windows, run the generated executable instead. Individual source files are separate exercises; they are not a single application.

## Purpose

Practice loops, arrays, functions, strings, structs, memory handling, and procedural problem solving.
